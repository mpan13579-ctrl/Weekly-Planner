# LP · 研判手册 v2.7

v2.7 ｜ 2026-07-21
**管什么**：③研判板块的流程工序与产出物质量标准——怎么记账读数（供需算账），怎么判定行情主导权（主导判定），怎么定档分流、出方向出节奏、成单交付（策略研判）。

**不管什么**：证据与因子加工（①②，本板块只持算法与读数权）；账户划分、资金与风险预算数值（④⑧）；下单执行与技术性锁仓操作（④⑤）；信息来源的取舍与合规判断（人域、人负责，不设系统条文）。

本手册＝③研判板块规矩层文件——上承《系统架构蓝图》与《指挥官手册》，下接实现方案与代码（手册先行）；红线1–5 见蓝图 §0.2。
## 术语定义（四轴，各轴各用各的词）

| 轴 | 取值 | 定义 |
|----|----|----|
| **机会级别**（定档判定） | 罕见级候选 ／ 标准级 ／ 不达标 | 描述失衡读数的量级，由策1 定档分流判出 |
| **台账档位**（立项结果） | 甲级方向 ／ 标准方向 ／ 无方向 | 描述品种当前方向资格，登记于策5 方向台账；甲级＝罕见级候选经战略法全工序＋人终裁通过 |
| **研判工序**（做法） | 战略法 ／ 战术法 | 两套并行做法：方向工序与节奏工序 |
| **账户**（资金） | 战略户（大资金）／ 战术户（小资金） | 账户与资金细化归④⑧；金额不定义级别，级别定资格 |

映射一行：**罕见级候选→战略法→（通过）甲级方向→战略户；标准级→战术法→标准方向→战术户；不达标→无方向→不交易。**

## 第一篇 · 研判流程（三子模块十五条）

### 流程总览

| 工序 | 频率／触发 | 产出 |
|----|----|----|
| 供需算账（算1–算5） | 常驻滚动 | 平衡表＋价格结构台账＋失衡读数 |
| 主导判定（主1–主3） | 低频定期＋事件触发 | 三态＋宏观权重 |
| 定档分流（策1） | 读数更新即判 | 罕见级候选／标准级／不达标 |
| 战略法（策2） | 罕见级触发；突发事件快轨 | 甲级方向结论单 |
| 战术法（策3） | 日频盘前＋盘中事件 | 战术开单提案 |
| 孵化池（策4） | 常驻跟踪 | 转正／退出 |
| 人终裁与交付（策7） | 呈单时／出手后 | 三键；五要素冻结交④、失效挂⑥、影子⑦、禁区⑧ |

### 子模块一 · 供需算账（常驻地基：记什么、读出什么）

| 条名 | 名称 | 条文 |
|----|----|----|
| 算1 | 品种池管理 | 全市场（约 80 个上市品种）→活跃池（＝蓝图扫描池的门槛化实现；流动性门槛：成交／持仓金额线、上市时长）→关注池→核心池。相关性高的同质替代品对只留流动性强者，同一产业链上下游品种不作去重（链间传导是信号源）；政策与流动性风险一票否决进禁做名单。池间准入：活跃池＝流动性门槛达标（见参数表）；关注池＝活跃池中任一失衡读数进入关注区（见参数表）或有信息差线索（算4）；核心池＝人从关注池圈定，设上限品种数（上限见参数表）。升降级月度定期复核＋读数触发即时升池。AI 扫描全活跃池，人深耕核心池。 |
| 算2 | 平衡表维护 | 活跃池全覆盖逐品种滚动维护（活跃池机器自动记账，核心池人工深耕＋一手信号交叉核验〔算4〕）——供给侧：成本／利润／产量／库存／进口／产能与在建产能（资本开支周期）；需求侧：消费／替代／出口；关联维度：产业链上下游品种的成本与利润传导（成本挤压、加工利润倒挤开工率）。维护频率随数据源节奏：周度为主、报告日加频、突发事件快轨即时重算（策2）；断更／缺数亮灯呈人。平衡表修正方向单列：缺口的边际转向（过剩转短缺／短缺转过剩）作独立读数登记，供算5 与策2 取用（预判差优先看修正方向、非绝对水平）。记账物理在①②，算法与读数权在③。 |
| 算3 | 价格结构台账 | 基差／期现／仓单／持仓日频滚动记录；国际联动品种加记内外盘比价与进口盈亏。与平衡表并列，构成市场面资金面数据底账。断更亮灯同算2。 |
| 算4 | 信息差生产 | 调研与一手信号采集入账，常驻主动工序，按品种排期滚动覆盖（核心池必覆盖）；产业末梢独家信号并入喂账，供算2 交叉核验与策2 供需算账核实取用；断更亮灯同算2。 |
| 算5 | 失衡读数 | 五项读数计算口径——①供需缺口幅度＝（供给−需求）÷年消费量（当期滚动与年度预估的取用由实现文件声明）；②库存历史分位＝当前库消比（显性库存÷年消费量）在分位窗口内的分位为主口径，绝对库存分位并列作参照；③行业利润分位＝当前行业利润在分位窗口内的分位；④成本线位置＝现价对全行业成本曲线的分位（现价之下产能占比；成本曲线由②供给，暂缺时用加权平均成本过渡并标注）；⑤行业亏损面＝亏损产能占比（口径同④成本曲线）。分位窗口＝滚动 N 年为主、全历史参照（N 见参数表；口径同附录二通用分位口径）。每项读数同时给出判向（多／空／中性，判向线见参数表），供策1 标准级判定。更新频率与断更亮灯同算2。读数喂给策1 定档分流（读数更新即判）。 |

### 子模块二 · 主导判定（状态量：谁说了算）

| 条名 | 名称 | 条文 |
|----|----|----|
| 主1 | 三态判定 | 品种主导／宏观主导／极端三态，判「当前行情谁说了算」；判状态，不做宏观预测。构成要件（输入见主3）：品种主导＝默认态（联动度低档且宏观脉冲无急变在场）；宏观主导＝联动度骤升至高档，或高频脉冲项急变在场，且持续达确认窗（窗见参数表）；极端＝宏观主导要件＋全板块同向共振＋系统性风险事件叠加，事件快轨常开。宏观主导与极端态须同时判宏观方向（利多商品／利空商品／板块分化，分化时逐板块给向），方向由在场脉冲项的方向属性合成（各项方向属性随参数表清单登记），供主2 钳制取向。退出口径（滞回）：宏观主导／极端态构成要件消失并持续 ≥ 退出确认窗（见参数表，严于进入窗）方降回品种主导；事件快轨进入的同守退出窗、不即时回落。 |
| 主2 | 压制机制 | 宏观权重＝主1 三态的直接映射，不设独立数值：品种主导→低档（无钳制）；宏观主导→高档；极端→高档＋事件快轨常开。高档钳制逐品种作用，作用面＝联动度高档（主3①）且方向与宏观反向的品种，品种自证成立（主3③）者豁免——钳制面随实测联动度伸缩，不随状态标签全池生效，单次状态误判的影响面由此封顶。钳制方式：①作用面内的战术反向提案降级呈现＋强制附宏观冲突标注（信号不停开，开单须人豁免留痕，同研4）；同向提案照常走开单三关。②战略法立项不受钳制、照常走全工序，结论单强制附情景分支（按研8）与宏观冲突段。③存量有效单复核范围同研4。与观点无关的全局硬动作只存在于⑧回撤规则，本板块不设。压制冲突处理按研4。 |
| 主3 | 更新机制与输入细则 | 复核节奏＝月度定期＋事件触发即时重判；触发事件：商品全板块同向共振（普涨普跌，口径线见参数表）、央行议息与重大流动性事件、地缘系统性事件、宏观脉冲清单项急变。判定输入三类——①商品间联动度：核心池品种与商品指数、品种两两间的滚动相关性（多档窗口，口径由②按声明落档计算）；联动度骤升＝宏观主导信号；档位用层级排序不设统一数值线，档位线见参数表。②宏观脉冲在场性：高频＋低频两张清单（清单本体与各项方向属性见参数表，可增删、人签）。③品种自证：逐品种标注宏观／中观／微观三层驱动，宏观栏空＋与板块指数背离走独立行情＝品种主导自证。三态构成要件见主1，三类输入的计算与档位口径由实现文件声明落档。切换生效：按声明口径判出即自动生效＋亮灯通报，人可否决回滚（留痕）；单次误判影响面由主2 逐品种作用面封顶。每次变更记录时点、依据与触发源，切换史入台账（溯源同研11）并进研12 影子对账、按声明口径结算命中。 |

### 战术法工艺细则（艺1–艺5，策3 之细目）

研判侧读盘判据。执行动作（加减仓节奏、止损挂法、锁仓）归④⑤，指挥官手册进7／进8／进13／进15 不入本表。

## 第二篇 · 产出物质量标准（研1–研15，两法产物同标准；标准层不组织流程）

| 条名 | 名称 | 条文 |

| 研1 | 双轨独立 | 逻辑轨（AI 逻辑研判）与因子轨（因子量化打分，打分口径由实现文件声明落档、非语言模型自产，对外称「方向参考」）互不可见、各自成稿，比对后同呈；两轨分歧必须原样呈现并留痕，不得抹平。 |
| 研2 | 分歧终裁 | 系统合成方向＝逻辑轨 结论（逻辑轨 全程受基率起手〔研6〕、溯源冻结〔研11〕、反方强制〔研14〕纠偏约束，因子轨 无同等配套、仅作方向参考）；人终审对每张单作采纳／修改／驳回，修改与驳回必写理由留痕。人可在展开机器结论前先录自己的事前观点（可选不强制），供人机分歧复盘对照。机器结论对人只是输入，不是默认答案。 |
| 研3 | 人工立项 | 人可不经机器直接立结论单，同样按五要素成单、同样进影子对账；人工单成单前同过一道独立反方审察（只呈示不改判、不加闸），机器补挂基率段，审察源分箱含人工单。机器缺席或出不了结论时，研判不停摆，此时审察与基率段容缺、单上如实标注。 |
| 研4 | 压制冲突与状态级联 | 主导判定压制品种信号时，被压制品种出现强逻辑→冲突预警亮灯呈人，人可一键发起主导判定重跑；反向强度以②证据流为输入、按声明口径计算，不依赖品种侧已有成稿（被压制品种的反向预警同样有效）。主导状态切换（三态变更）时，主2 作用面内（联动度高档且与新宏观方向反向，板块分化时按板块对表）的存量有效单自动亮灯失效复核，由人处置、不自动作废。结构上禁无人自动环路；人豁免压制须留痕。 |
| 研5 | 五要素成单 | 方向、核心驱动、预期路径、失效条件、时间窗五要素（同指挥官手册 D3）齐备才成结论单。单上内容数值同守红线5：时间窗从档位菜单取值（菜单见附录三）并挂事件锚（研7 日历事件）或明标「无事件锚」；失效条件阈值与预期路径价位须两跳溯源到②证据源，给不出证据源的改语义型或不成单（多空单须保有至少一条阈值型，无则不成单，见下句）。发出即冻结，改观点＝作废旧单另立新单；同品种同法至多一张有效单——任一触发遇存量有效单，结论无实质变化记「维持」不另出单，有实质变化出新稿呈人、人采纳后旧单作废；「实质变化」＝五要素逐项比对、任一要素变化即实质，核心驱动与预期路径的语义比对存疑时一律出新稿呈人（宁呈勿吞）。失效条件必须可判定（阈值型或语义型）；多空单须至少含一条阈值型失效条件（④算止损距离与盈亏比之需），观望单可仅语义型；语义型须附判定边界例（「算」与「不算」至少各一条）并声明判定归属，⑥判定存疑一律亮灯呈人；成单即交⑥订阅监测，⑥报失效条件成立一律亮灯呈人，人确认后单作废（联动降档按策5）。 |
| 研6 | 基率起手 | 战略法与战术法研判的第一道工序＝先答「这类情形历史上怎么走」（相似案例＋历史频率），再进本案论证；相似案例与历史频率由②按声明口径计算供给，逻辑轨 只引用与解读、不得自产数字；此次序为逻辑轨提示词硬规则，缺基率段的稿不成形；冷启动样本不足时段内如实标注「样本不足」，照常成稿不误研判。 |
| 研7 | 事件日历 | 已知催化剂（政策窗口、数据发布、交割、假说时间窗到期）汇成全局一张日历，盘前对表；命题的催化剂与时间窗自动挂历，到期自动亮灯。 |
| 研8 | 情景分支（窄口径） | 仅主导判定、罕见级立项与重仓命题出情景分支：每个情景挂催化剂、失效点、预案；重仓命题认定以④⑧提供的仓位口径为反向输入（认定结构见附录三，阈值挂账④⑧）。其余品种命题维持单一假说，不铺情景树。 |
| 研9 | 概率与置信分列 | 方向倾向（多／空／观望三键）与判断置信（强／中／弱）分列表达，不得混用一个字段；置信三档与指挥官手册 D10 确信度（高／中／低）为同一字段两种称谓，给档规则由实现文件声明（禁逻辑轨 无规则自评）；三档对应的数值区间约定见参数表，数值区间仅由影子实测标定、升档后启用。 |
| 研10 | 冷启动与升档 | 冷启动期方向判断只用定性档，主导判定（主1 三态与宏观方向）之概率表达冷启动期同由置信定性档承载；升数值概率档的唯一路径＝影子系统分箱命中达标（条件见附录三），达标前概率字段保持空值。升档样本以同一引擎大版本为界，引擎变更在影子台账记断点（小改不重置、大改分段，粒度见参数表）；升档后分箱持续监测，连续失准跌破门槛的档位概率字段回空、退回定性档（条件见附录三）。 |
| 研11 | 溯源冻结 | 结论单上任何取值可在两跳内溯源到证据源；结论当刻的证据基础快照冻结，单上同时记录产稿引擎版本（模型与提示词／方法论底料版号）；研判库只增不改。②侧声明口径发生定义变更时通告研判层，引用该口径的存量有效单与基率段自动亮灯复核。提示词、方法论底料与合成规则（研2）的变更须准入：机器只提名、人签后生效（同研13 模式），生效即在影子台账记断点。 |
| 研12 | 影子实证 | 全部结论单按「人的处置（采纳／修改／驳回）×单的方向（多／空／观望）」两轴一律进影子在册对账，按轨、按置信档、按审察源分箱统计命中。命中由影子系统按声明口径判定：单按时间窗到期时点结算，期内失效条件触发的按触发时点结算；作废单照原时间窗结算、不出册；到期单自然结算退役（判定细则见附录三）；判定口径自身同样版本化，口径变更记台账断点、存量分箱按口径分段不跨口径混算。「不足」记录在案但不入命中分箱；采纳率、推翻率、不足率、观望率与压制豁免频率同板可见。判断质量以影子前向实证为唯一真值；指标只记录、不作奖惩考核，研10 升档标定为条文明定的唯一例外用途。 |
| 研13 | 禁区回灌 | 复盘证伪的逻辑进研究禁区清单——入区须人签、机器只提名，单次失效不自动入区；清单作逻辑轨必读负面清单：禁以清单内逻辑作正方论据，同向证据必须转入反方栏呈现；清单年度复审，复活须人签。 |
| 研14 | 反方强制 | 机器每份方向稿必须自带至少两条挂证据的反方论据，空话不算数；成单前另过一道独立反方审察（只挑最强反驳并标削弱度〔档位制，档位口径由实现文件声明落档，禁自评数值〕，不改判、不加闸），审察与逻辑轨 异源（不同供应商谱系模型），异源暂不可用时审察照跑、单上标注「同源审察」、影子对账按审察源分列；呈递时反方与正方同屏并置，不得折叠隐藏。反方缺席的稿不成形；审察缺席须在单上如实标注。 |
| 研15 | 不足披露与缺口回写 | 证据不足以支撑判定时，机器必须如实报「不足」，不得硬出方向；「不足」与主动观望是两回事（观望＝有论据的判断，不足＝判不了），不得混用。「不足」不成单但照常呈人知悉，并自动生成「缺什么数据」清单回写①②补数，补齐可重跑。缺数清单按求证工单出题：逐项写明用途与闭合判据（要什么数／什么口径／几个源），交②走 2-2 求证获取；缺口闭没闭合由②对判据验收、不闭续题，③只出题、不自己找料。本手册各处缺数情形（算2 断更缺数、策1 缺数存疑、研6 样本不足、策2 定价对照容缺）回写补数时同用此工单形态，原有呈人／容缺标注／照常成稿等处置不变。 |

## 附录二 · 参数标定方法
**罕见级四条判定线定值与校准**：初版值按行业锚＋历史大行情案例人工对账直接定值呈签，不以回测模块为前置——多头型对账 2015–16 螺纹钢、2020 玻璃、2023–24 碳酸锂底部、生猪周期底部；空头型对账 2023 碳酸锂顶、2021 生猪顶、聚酯产业链产能投放周期。回扫复核为后置校准手段：①数据——逐品种上市以来的缺口比／库存分位／利润分位／成本位置序列，由①②供给；上市年限不足门槛的品种借用强相关品种参照并如实标注。②回扫复核——上线后对生效线在历史序列上回扫，产出各线下的「罕见级在场时段」清单，与历史大行情案例清单人工对账。③校准原则——召回优先：先保证历史级别大行情全部命中，再收窄误报；收窄误报时同步检查未入选的次级行情案例不被误杀（旁证集由人圈定），防对少数对账案例过拟合；全市场统一线起步，品种系数留作二期。④修订生效——影子期实测与回扫结果呈人认定后修订参数表并版本化（同研11 模式）；年度或数据口径变更时重扫复核。标准级判向线、关注区线、定价对照评档线按同一套路校准。

**通用分位口径**：全手册各「历史分位」除另有声明外，一律＝滚动 N 年窗口为主、全历史参照（N 见参数表）；库存类分位一律以库消比为主口径、绝对库存作参照（算5②）；季节性显著品种（农产品作物年度、能源取暖季等）的库存与缺口分位先按日历同期窗口对齐再取分位，名单由实现文件声明、人签；窗口与公式变更按研11 通告与亮灯复核。

**其余参数归属**：有历史序列可回测者（判向线／关注区线／拥挤度线／共振口径线）初版起步后按上方案回扫校准；行为与口径类参数（联动度档位、确认窗、冲突预警线、时间窗菜单、命中口径、引擎分段粒度）初版为人签经验值、影子期实测校准修订；盈亏比门槛指挥官已定值（硬门槛＋观察线＋校准池反推，见参数表策3 行）；流动性门槛按行业惯例值起步人签。
## 附录三 · 引用细则骨架（研5／研8／研10／研11／研12 之附录本体）

骨架层定结构与规则；具体计算口径（交易日历对齐、基准价取法、波动率带公式等）由实现文件声明落档。

### 附三1 · 时间窗档位菜单（研5 引用）

| 档位 | 窗长 | 默认适用 |
|----|----|----|
| 事件窗 | 事件锚前后 ±1–5 个交易日（随事件类型定） | 事件对表命题（艺3／研7） |
| 短窗 | 5–10 个交易日 | 战术开单提案（策3）默认档 |
| 中窗 | 20–60 个交易日 | 标准方向命题默认档 |
| 长窗 | 一季至一年 | 甲级方向与孵化池转正命题默认档，可续挂 |

- **挂法**：单上时间窗＝档位＋到期日。有事件锚（研7 四类：政策／数据／交割／到期）→窗长对齐锚点、到期日＝锚点日或锚点后确认日；无事件锚→取档位默认窗长、明标「无事件锚」。默认档仅为起手值，成单时人可改档（留痕）。
- **到期动作**：到期自动亮灯（研7）、按研12 结算；续期＝作废旧单另立新单（研5 冻结规则，不允许原单改窗）。

### 附三2 · 命中判定细则骨架（研12 引用）

- **方向对错基准**：以成单冻结时点的基准价（成单日收盘价或结算价，取法由实现文件声明）对结算时点价格的涨跌方向，对照单方向判对／错。
- **幅度线结构**：两带制——噪声带（涨跌幅在带内不判对错，记「未及幅度」，在册不入对错分箱）；有效幅度（越带才计对／错）。噪声带初版 ±2%，或按窗长匹配的波动率带（如窗内平均真实波幅倍数），择一由实现文件声明落档；分品种波动率分档留二期。
- **观望单口径**：期内价格始终未出噪声带＝命中；出带＝不命中（结论单口径的镜像）。
- **结算时点规则**：到期单按时间窗到期时点结算；期内失效条件触发的按触发时点结算；作废单照原时间窗结算、不出册；驳回单照常入驳回箱结算（研12 两轴）。结算日无行情（长假、停牌）顺延至次一交易日。
- **版本化**：口径变更记台账断点、存量分箱按口径分段不跨口径混算（同研12）。

### 附三3 · 升档／降档条件骨架（研10 引用）

- **分箱轴**：按轨（逻辑／因子）×置信档（强／中／弱）×审察源（异源／同源），同研12 分箱；逐分箱独立升降。
- **升档条件**（两件同时满足）：①分箱方向命中率显著高于蒙对基率（50%）——显著性判定含全部分箱的多重比较校正，初版整数值二档任达其一：结算单样本 ≥50 且命中率 ≥70%，或样本 ≥100 且命中率 ≥64%，精确检验口径由实现文件声明落档；②置信档序单调不倒挂（强 ≥ 中 ≥ 弱）。满足后该分箱启用数值概率区间，区间值由影子实测标定回写参数表（研9 行）。
- **降档条件**：升档后滚动最近 20 张结算单命中率 \<50%，且连续 2 个月度复核期不回升→该分箱概率字段回空、退回定性档。
- **断点**：引擎大版本变更分段统计、不跨段混算（分段粒度见参数表）；样本量与门槛为初版人签值，影子期实测校准。

### 附三4 · 重仓命题认定骨架（研8 引用）

- **用途**：研8 情景分支适用线之一——重仓命题必出情景分支。
- **认定输入**＝④⑧供给的仓位口径（品种敞口占户内风险预算比／占总敞口比，日频），作研判的反向输入。
- **阈值形式**：品种敞口占比 ≥ 线（战略户／战术户分列）；线值待④⑧口径定稿后填入参数表。
- **挂账声明**：④⑧现未供数——数值挂账、不自造（红线5）；过渡期由人工认定（指挥官点名即按重仓命题处理，留痕）。

### 附三5 · 合成规则挑战者转正（研2／研11 引用）

- **现任与挑战者**：逻辑轨为现任合成源；因子轨及各审察源分箱为挑战者，在研12 影子同板对账。
- **转正条件**：挑战者分箱达附三3 升档条件，且连续 2 个月度复核期命中率高于逻辑轨对应分箱→机器提名合成规则变更，人签生效（研11 准入），影子台账记断点。
- **回切**：原任转挑战者继续在册，同条件可回切。
