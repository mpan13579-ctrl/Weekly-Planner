**管什么：**②分析取证板块的证据与因子加工——从①数据底座取数，算出③研判所需的读数原料、证据、基率与因子轨打分，并对一切加工口径声明落档。

**不管什么：**数据的采集、清洗、存储与治理（归①，②不建库）；研判读数的算法定义与方向结论（算法与读数权在③，②只供数与证据、不出方向）；参数数值的裁定（归③参数表与各板块）；**制度参数**（限仓、费率、交割日历等交易所既定事实数据）的采集与维护（归①，②只取用不维护——2026-07-21 与④对齐）。

**①②边界：**①管库，②管算。②经①取用站接口取数，产物按机产账回写①的库（自动立户）。平衡表原始科目（产量／库存／进口等）属①外产账；衍生物（缺口比、修正方向等）属②算完回写的机产账。②继承①三条铁规矩：截时取数（可重算、不掺未来信息）／标记透传（存疑、过期等标记随血缘带进②产物）／红线5（一切数值出自声明口径，语言模型不得自产数值）。

本手册＝②板块规矩层文件——上承《系统架构蓝图》与《业务闭环全景图》，下接实现方案与代码（手册先行）。模块编号：①数据底座 ②分析取证（本手册板块）③研判定向 ④仓位进出 ⑤审批下单 ⑥监控预警 ⑦复盘归因 ⑧风控总闸。

## 四 · 加工流程（十模块条文）

条文按骨架三层编号：**料**＝原料加工层（②1／②2／②6）、**证**＝读数证据层（②3／②4／②5）、**支**＝研判支撑层（②7／②8）、**治**＝横切层（②9／②10）。参数数值一律不写在条文里，集中于第六章，条文只引参数名。

### ②1 平衡表加工（料1–料5）

| 条 | 条名 | 条文 |
|----|----|----|
| 料1 | 科目立账 | 逐品种立供需科目一套：供给侧＝成本／利润／产量／库存／进口／产能与在建产能；需求侧＝消费／替代／出口；关联维度＝产业链上下游成本利润传导。科目原始数据一律经①取用站取得，②不自行采集。科目清单随品种特性增删，属语义类变更、人签。 |
| 料2 | 滚动维护 | 平衡表随①数据源节奏滚动重算：周度为基准，官方报告日加频，事件档即时重算。活跃池全覆盖，核心池加密。每次重算记输入数据截止时点。 |
| 料3 | 缺口计算 | 供需缺口比＝（供给－需求）÷年消费量。当期滚动与年度预估两口径并出，取用哪一口径由③声明。分母年消费量不可得的品种，缺口比记「不可得」并入容缺清单，不以估算充实测（见质6）。 |
| 料4 | 修正方向单列 | 相邻两期缺口比的边际转向（过剩转短缺／短缺转过剩／同向加深）作独立读数登记输出，不并入缺口水平值、不与水平值合成单一指标。 |
| 料5 | 交叉核验 | 核心池平衡表与①的一手信号交叉核验（对应③算4）。不一致处不擅自取舍，挂存疑标记随产物透传至③，由③按其研判规矩处置。 |

### ②2 价格结构加工（料6–料9）

| 条 | 条名 | 条文 |
|----|----|----|
| 料6 | 基差月差 | 日频计算基差率（现货对期货）、月差结构（近远月价差）及月差变化率。水平值与变化率并列输出，不合并。 |
| 料7 | 仓单期现 | 日频登记仓单量及其变动、期现价差、持仓量。断更超过声明容忍期的，输出打过期标记。 |
| 料8 | 内外盘 | 国际联动品种计算内外盘比价与进口盈亏。汇率取①在册源，按发生时间取最近已发布值，与①的时点查表口径一致，不用事后修订值回填历史。 |
| 料9 | 换月处理 | 主力换月窗口打标记；移仓成本与换月造成的基差跳变单列为成本与时机项输出，不并入方向类读数（对应③艺4）。历史序列跨换月处理方式在②10 声明后统一执行。 |

### ②6 资金持仓加工（料10–料13）

| 条 | 条名 | 条文 |
|----|----|----|
| 料10 | 席位持仓 | 计算前20会员多空持仓与净持仓、派系集中度。国内持仓数据套保套利混杂、无商业与非商业分类，②只出持仓事实与集中度，不出「主力方向」判断（对应③艺2 边界）。该差异随产物标注。 |
| 料11 | 拥挤度 | 计算成交持仓比及其自身历史分位、本方向持仓分位。分位窗口同证2。 |
| 料12 | 超常规模 | 单席位持仓或派系集中度达线者打标输出（线值归第六章、现挂③参数表）。②只报事实，是否构成拥挤极值由③判。 |
| 料13 | 反向强度 | 按声明口径计算反向强度，供③研4。输入限②自身证据流（价格结构、持仓拥挤、一致预期分布、分位读数），**不回读③已有成稿**，避免环路。②输出连续值，弱／中／强档位线归③参数表。 |

### ②3 成本曲线与分位读数原料（证1–证5）

| 条 | 条名 | 条文 |
|----|----|----|
| 证1 | 成本曲线 | 以装置级成本数据排序成全行业成本曲线，输出现价之下产能占比与亏损产能占比，两者同口径（对应③算5④⑤）。装置级数据不可得时，按③算5④ 既有降级口径以加权平均成本过渡并标注降级。 |
| 证2 | 分位口径 | 一切分位一律滚动 N 年为主口径、全历史为参照口径，两者并出。季节性显著品种先按日历同期窗口对齐再取分位；适用名单属语义类、人签。 |
| 证3 | 库存分位 | 库消比（显性库存÷年消费量）为主口径，绝对库存分位并列输出。年消费量不可得的品种：绝对库存分位照出，主口径记「不可得」，是否允许其顶替主口径待③补降级口径（见衔接下1），②不自行认定顶替。 |
| 证4 | 利润分位 | 行业利润在分位窗口内的分位。利润口径（现货利润／盘面利润）分别计算并分别标注，不混用。 |
| 证5 | 样本不足 | 上市年限不足分位窗口的品种，用全史计算并标注「窗口不足」；样本量低于成分位下限者输出「样本不足」，不外推、不借用其他品种数值充数。 |

### ②4 定价对照证据（证6–证11）

| 条 | 条名 | 条文 |
|----|----|----|
| 证6 | 价格位置 | 计算现价向失衡指向目标区（成本线／历史分位区）已走比例。目标区取值来源随产物标注。 |
| 证7 | 一致预期 | 汇总研报共识与舆情的方向分布统计。输入为①打标站产出的分类标签与计数，②只做汇总统计、不新增判断、不生成新数值（见质7）。暂缺时按③策2 人工录入并容缺标注。 |
| 证8 | 持仓拥挤 | 直取②6 料11 输出，不另立口径、不重复计算。 |
| 证9 | 结构已走度 | 判基差与月差是否已沿失衡方向走出及走出程度，直取②2 输出。 |
| 证10 | 期权隐含 | 有期权品种计算隐含波动率与偏度，作第五类可选证据。无期权或数据暂缺的品种容缺标注，不因缺此项降低其余四类证据效力。 |
| 证11 | 评档输出 | 四类证据各出档位，合成「未定价／部分定价／充分定价」三档输出。情绪与拥挤类（证7／证8）只作用于下调已定价程度评档，不得独立构成立项或开单依据（对应③策2）。评档线经校准后回写③参数表，②不自定线值。 |

### ②5 联动度与宏观脉冲（证12–证15）

| 条 | 条名 | 条文 |
|----|----|----|
| 证12 | 联动度 | 计算核心池品种对商品指数、品种两两的滚动相关性，窗口 5／20／60／120 日四档并出，主判窗归③参数表。档位＝核心池内相关性层级排序三分位。 |
| 证13 | 骤升判定 | 档位跳升至高档、且自身相关性历史分位达线者输出骤升标记（线归③参数表）。②只出标记，是否构成联动主导由③主3 判。 |
| 证14 | 宏观脉冲 | 计算高频五项（美元指数／美债实际利率／恐慌指数／原油／经济政策不确定性指数）与低频五项（工业品出厂价格同比及预期差／货币剪刀差／全球制造业采购经理人指数／出口同比／中国信贷脉冲）。各项方向属性照③参数表清单登记，②不自定方向属性、不增删清单项。 |
| 证15 | 急变判定 | 按声明口径逐项判急变，输出在场标记与在场项计数。②不出宏观三态结论（三态判定权在③主1）。 |

### ②7 基率库（支1–支4）

判据经两轮锚定：先锚相邻领域权威做法（参照组预测／气象类比集合预报／案例推理／金融相似匹配／小样本统计），再对海外成品级现货回校（基率手册／债务危机模板库／农产品类比年服务／市场状态相似度产品／信号基率订阅产品，出处见附录一）。国内公开研究无完成品。

| 条 | 条名 | 条文 |
|----|----|----|
| 支1 | 案例立账 | 历史相似情形逐案入库，每案记：情形特征（失衡读数组合＋市场状态特征）、发生时点、其后各期走势。**立案边界用可核查硬指标定义**（哪些读数组合达到什么档位构成一个「情形」案例，判据在②10 声明落档）——案例库边界客观，不许语义化伸缩（海外现货通例：案例库入库门槛皆为单一可核查硬判据）。入库范围与回溯起点在②10 声明。制度断点（产能格局剧变、交割规则修改、品种上市初期）逐案打标，断点表人签。 |
| 支2 | 相似性判据 | 两层匹配：**先划类**——同品种为主，样本不足可扩至同板块强相关品种（须标注借用，同治2）；宏观三态与联动档作类别过滤，状态不同的历史时段不入候选。**类内算距离**——五项核心读数（缺口比含修正方向／库存分位／利润分位／成本位置／价格结构）的加权欧氏距离，读数皆为分位值、天然标准化；特征宁少勿多，增删特征属语义类、人签。权重初版等权，调权唯一依据＝影子与回扫验证误差反推，禁无验证调权，修订走签字闸版本化（同③研11 模式）；制度断点前样本按声明衰减系数打折。 |
| 支3 | 案例集取用与频率统计 | 不设绝对相似度门槛（无任何领域有公认门槛值），取最相似前 N 个（N 见第六章），并做距离体检：第 N 案例距离超过该品种历史案例两两距离分布的声明分位即截尾，截后剩几案算几案。对案例集统计后续走势的**分时间窗**方向频率（时间窗档位对齐③研5 时间窗菜单），不做长时间窗外推——相似情形预测力随持有期衰减为实证结论。**输出三列并排、样本数永随结果**：每档时间窗给「匹配案例数＋方向频率＋中位幅度」（抄海外信号基率产品通行呈现式）；幅度的分布细节（分位散布）仅案例数达上档线时输出，未达只出方向频率与中位幅度。只出频率与分布，不出方向结论。出数前做敏感性测试：换权重或换划类后结论翻转的，随基率段标注「结论不稳」。 |
| 支4 | 样本量分档 | 案例数三档分级处置：**低于下档线频率不出数**、输出「样本不足」，但匹配到的候选案例清单照供——逻辑轨可对少数强相似案例作定性对照（模板对齐路线：海外大事件库全库仅数十案仍可用，代偿即「只作案例对照、不报精确概率」），③研6 照常成稿不误研判；下档线至上档线之间出数、必须同呈频率的小样本置信区间（威尔逊区间），区间宽度随基率段呈现；上档线以上正常出数、仍带区间。两线值见第六章。不外推、不放宽判据凑数、不以未声明借用的相邻品种案例充数。 |

### ②11 缺口驱动求证回路（回1–回5）

立意：求证链（缺口→出题→获取上账归①→验收→闭合／续题／无果结案）要自动转起来，卡点只在「缺口靠人发现」。本模块把缺口由发现改为判定，例行自查从一句话变成台账字段级的缺口清单。2026-07-20 指挥官提出并认定。

| 条 | 条名 | 条文 |
|----|----|----|
| 回1 | 应供清单与双读数 | ②按需求侧账本维护应供清单（品种×口径×声明频率），逐字段挂两个读数：**新鲜度**（距上次更新几天）与**覆盖度**（应有品种与口径缺哪几块）。新鲜度线逐字段挂在该字段自己声明的更新节奏上，不设全局一刀。双读数监控的是「②应供对①实供」之差：缺口判定在②，补数走①管道，②不越界管①的库。 |
| 回2 | 自动出题 | 读数越线即机器自动生成求证题，不等人发现。同一缺口在既有题未闭合期间不重复出题（去重防自激）。人工出题通道（③点名要料、②打包发现缺）保留不废。 |
| 回3 | 闭合判据与续题升级 | 每道题出题时写死闭合判据：要什么数、什么口径、至少几个源。**②只出题与验收，不经手原料**——采集与上账归①，料一律走①管道入库后②再对判据机器验收（机械比对，不违红线5）。不闭合自动续题，连续若干轮不闭合升级推人（轮数上限见第六章）；**确认无源可得的按「求证无果」结案**——照实标注找过没找到、入容缺清单（质6），不悬空、不假闭合。 |
| 回4 | 研究深度分档 | 例行自查补数走便宜档；③点名要料与⑥突发事件触发的深研走贵档。档位划分与触发归属在实现方案落档，本条只立分档原则——研究量上去后此为成本生死线。 |
| 回5 | 工单台账与①边界 | 求证工单为②自持台账：每单记题目、闭合判据、状态（在办／闭合／无果结案）与来源指针（料到账后②自记其源与批次号）；归因排错查②的工单台账，**①不挂工单号、不判闭合、不持工单台账**。补数取道①既有机制、不要求①新增班次外采集：在册源之数等其班次；在册体系的新指标凭①条「缺户自动立」自动立户；新源走立户（人签，信息来源取舍归人域）；一次性料（报告／访谈／联网搜索所得）走①人工录入取法。「班次外按需采集」挂①手册候选债表，真实需求出现再立案。指标：**求证工单闭合率**＝出题数对闭合数（无果结案单列不计闭合），②侧自记；与①「缺口回写闭环率」（取数交付层）各归各家、不混称。 |

### ②12 信息线预警快线（快1–快5）

立意：信息线三截分工——①＝事实管道零判断／②＝快线判「值不值得推、什么档」／⑥＝嘴与账——2026-07-22 指挥官对表定案，⑥分3 落⑥侧、契约与⑤⑥承接落定，②侧对应模块本版骨架落档。**本模块判信息价值与档位、不判方向（不越质1）**：判的是「这条信息要不要推给人／给③看、什么档」，非多空方向。因子截时读细则、AI 轻判边界与置信下限、预警规则库与事件档位起步清单为实质研究，标**待深化研究**、归②实现方案；深化前不启用自动判档，按规则匹配保守出档、存疑一律标注上呈。

| 条 | 条名 | 条文 |
|----|----|----|
| 快1 | 判定源 | 两类入判：突发重大信息（①打标站事件流，逐件判）与日历事件（研7 日历／①发布与议息日历，②定档位判据、⑥照表推）。②只判不采——采集、清洗、打标归①，②经取用站取事件流与标记，不自采（同①②边界「①管库、②管算」）。 |
| 快2 | 判据三合 | 判「值不值得推、什么档」三路合成：①规则匹配——预警规则先行（语义类、人签，与策略同主同复盘，同③研判规则治理）；②因子截时读——取②现有读数与因子作价值权重（截时取数、不掺未来，同质4）；③AI 轻判——规则与因子判不尽的残余轻量判（实例无工具、无写权，同①指令扫描封装、红线5 不自产数值）。三路优先级、AI 轻判边界与置信下限**待深化研究**、归②实现方案。 |
| 快3 | 档位输出 | 出判定件＝「值不值得推」＋档位（高档／中低档），档位判据与⑥分3 咬合：高档→⑥即时级预警、中低档→⑥清单级信息（映射见⑥参数表，②定判据、⑥照判定件取档）。**②出判定件、不直推、不设第二张嘴**（承⑥分3）：判定件入⑥6-3 单一通道按档呈现，②不自设推送口。具体事件→档位判据起步清单（哪类事件何档）为语义类、人签，**待深化研究**。 |
| 快4 | 双道分流 | 判定件双道走：①一道给⑥——作信息线触发源入⑥，按档呈人（快3）；②一道发**触发信号**给③——看是否生成／调整策略（③承接产物为回路闭合判据）。信号不回传内容、不发①；②为判定源、③复核后不回发（同⑥分3 双道）。 |
| 快5 | 标记透传与对账 | 存疑／容缺／降级标记随判定件透传两头——⑥呈人必显示、③复核可见，②不抹平（承质5＋⑥处1）；判定件与⑥推送逐件对账，漏接亮灯（承⑥分3／供1）。预警量与误扰率入⑦统计、校②档位判据（⑦终3 立此回路），②据⑦统计修档位判据、走签字闸版本化，不由⑥人工节流。 |

## 五 · 产出物质量标准（质1–质8）

本章为②一切产物的通用规矩，与第四章条文同等效力；两者冲突时以本章为准。

| 条 | 条名 | 条文 |
|----|----|----|
| 质1 | 不出方向不越界 | ②只供数与证据。方向结论归③、参数修订权在③、仓位口径归④⑧。②产物不得含方向判断语句，不自改③参数，不代④⑧定值。 |
| 质2 | 两跳可溯源 | ②每一笔输出可在两跳内溯源至①的证据源。供③研5 阈值型失效条件之用者，须附完整字段链路（对应账本第 13 笔）。 |
| 质3 | 阈值证据供给 | 多空单所需的阈值型失效条件证据由②供给。可充当阈值型证据者＝有明确数值口径的产物：价格结构类（料6–料9）、分位读数类（证2–证5、料11）、成本线类（证1）。②供不出可溯源阈值证据时即时告警③，不静默——避免③侧无声不成单（对应衔接下7）。**技术价位不充当阈值型证据**：前低、平台位、均线等图形位不入上述三类。排除理由非「不可溯源」（图形位可由①价格数据算得、链路是通的），而是**它不证伪核心驱动**——失效条件的作用是「这条判断被推翻的证据」，价格跌破前低只说明价格走了、不说明产业逻辑错了；与已认定裁定「量价技术类只作方向参考、不单独成读数喂策1」一脉。④设止损锚同守此条，避免一单两锚。 |
| 质4 | 截时取数 | 一切历史序列、回扫与滚动分位按①条「截时取数」执行，只认落库时间，不掺未来信息，须可重算。②内部缓存与派生序列同守此条。 |
| 质5 | 标记透传与合并 | ①的标记（存疑／降级／独家／试用／过期／指令命中／无关）随血缘透进②产物并继续透给③。多源输入的标记合并就重不就轻：任一输入含存疑或过期标记，输出即继承该标记。 |
| 质6 | 容缺不硬出 | 数据不可得时如实输出「不可得」或「样本不足」并标注，不以估算充实测、不硬出数、不静默留空。容缺清单逐品种维护，随产物可见（对应③研15）。 |
| 质7 | 红线5 遵从 | 一切数值出自声明口径的计算。文本提取类证据（一致预期、舆情）所得为分类标签与计数统计，非语言模型自产数值；该性质须随产物声明。 |
| 质8 | 回写机产账 | ②产物按机产账回写①的库、自动立户，②不自建库、不旁路取数。回写指标清单与①范围表对表，册外自动拒收。 |
